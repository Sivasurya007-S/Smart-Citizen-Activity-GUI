#Smart Citizen Activity 
I’m excited to share our project, **UrbanPulse – Smart City Citizen Analytics Dashboard** 🌆

This project was collaboratively developed by **Sivasurya, Abdul Rahman, and Srianbu** using Streamlit, Machine Learning, and Plotly to create an intelligent smart-city analytics platform.

🚀 Key Features:
• Carbon Footprint Prediction using Regression Models
• Activity Level Classification using ML Algorithms
• Interactive Analytics with Pie, Polar & Area Charts
• Age-Group Comparison Analytics (18–24, 25–39, 40–59, 60+)
• AI-Based Smart Recommendations for sustainability and healthy living
• Modern Glassmorphism UI with advanced visualizations

💡 The Vision
Our objective was to build more than a traditional dashboard by integrating machine learning, predictive analytics, and smart visualizations into a real-world smart-city solution capable of analyzing citizen lifestyle behavior and sustainability patterns.

🧠 Technologies Used:
Python • Streamlit • Scikit-learn • NumPy • Plotly • Machine Learning • Data Visualization

This project provided us with valuable experience in ML model integration, dashboard development, predictive analytics, and modern UI design while working as a collaborative team.

We are excited to further enhance UrbanPulse with future features such as real-time analytics, IoT integration, and advanced citizen behavior prediction systems.
