# 🌆 UrbanPulse – Smart City Citizen Analytics Dashboard

UrbanPulse is an AI-powered Smart City Analytics Dashboard developed by **Sivasurya, Abdul Rahman, and Srianbu**. Built using Streamlit, Machine Learning, and Plotly, the platform analyzes citizen lifestyle data to generate insights on sustainability, health, energy efficiency, and overall lifestyle performance.

The system utilizes regression and classification models to predict carbon footprint and activity levels while providing interactive visualizations, age-group comparison analytics, and personalized recommendations. Features include sustainability scoring, health performance analysis, energy efficiency tracking, and dynamic dashboards powered by Plotly.

### Technologies Used

* Python
* Streamlit
* Scikit-learn
* NumPy
* Plotly
* Machine Learning

### Key Features

* Carbon Footprint Prediction
* Activity Level Classification
* Smart Lifestyle Analytics
* Age-Group Performance Comparison
* Interactive Data Visualizations
* AI-Based Recommendations
* Modern Glassmorphism User Interface

UrbanPulse demonstrates the integration of machine learning, data analytics, and dashboard development to support data-driven decision-making in smart-city environments.
